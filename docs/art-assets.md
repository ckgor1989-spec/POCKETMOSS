## 2. 精灵规格（15 只）

### 2.1 渲染管线（`js/sprites.js`）
1. **48×48 逻辑像素**画布，用几何基元（椭圆 / 三角 / 胶囊 / 矩形）铺「色块蒙版」，记号 9 种：`.` 透明、`b` 本体、`A` 点缀、`w` 白、`e` 眼、`k` 腮红
2. **自动描边**：蒙版外紧贴实体的像素统一填 `mix(shadowColor×0.4, #2f2b4a, 0.6)` 的藏青墨线
3. **4 阶明暗**：按（x+y）对角光照计算 `u`，切分 `[0.18, 0.56, 0.84]` 四段（高光 / 本体 / 阴影 / 深阴影）
4. **棋盘抖动**：在每段交界 ±0.05 内按 `(x+y)%2` 交错相邻色阶，形成 GBA 式过渡
5. **顶部轮廓光**：每列最顶端像素提亮 55%
6. **内缘压暗**：贴近墨线的像素与描边色混合 50%，强化剪影
7. 眼睛 = 深色椭圆 `#171423` + 左上 2px 白高光；腮红 = 3px `#ff9ab2`

### 2.2 场景内尺寸与排布（`SceneRenderer.computePetPositions`）
| 项目 | 规格 |
|---|---|
| 显示尺寸 | canvas 高 **120px**（48px 点阵 × 2.5 倍），`image-rendering: pixelated` |
| 容器 | 120 × 144 px，`translate(-50%,-50%)` 锚定脚底中心 |
| 透视缩放 | `scale = 0.66 + depth × 0.60`（0 → 0.66 倍，1 → 1.26 倍） |
| 地平线 | `H × 0.62`，脚底在 `horizon → H-18` 之间按 depth 插值 |
| 防裁切 | `y = min(... , H - 71×scale - 8)` |
| 横向排布 | N 只按 `0.5 + (i-(n-1)/2) × 0.165` 屏宽，clamp 0.15–0.85，±5% 随机抖动 |
| 地板投影 | 72 × 12 px 椭圆 `#2f2b4a`，透明度 0.20 |
| 待机浮动 | ±4px，2.6s 循环，随机负延迟错相位 |
| 进化标记 | 右上角 `✦` `#fde047` |

## 3. 场景渲染规格

### 3.1 低分辨率管线（`js/renderer.js`）
- 场景画布先画在 **1/2 分辨率** offscreen（`PX = 2`，`LW = W/2`、`LH = H/2`）
- 主画布 `imageSmoothingEnabled = false` 后 `drawImage(low, 0, 0, W, H)` 铺满，得到硬边像素块
- 每帧顺序：天空 → 彩旗（洞窟除外）→ 远景 → 地面 → 近景道具 → 粒子 → 放大 blit

### 3.2 通用层
| 层 | 规格 |
|---|---|
| 天空 | 地平线以上 12 条色带，`skyTop → skyMid → skyBot` 插值 |
| 太阳 | 半径 10/8 逻辑 px，位于 `(0.84LW, 0.12LH)`，左上 2px 高光 |
| 云 | 4 团三圆叠加，按 `t×(2+i)` 横向漂移循环，底部 `cloudShade` 压边 |
| 彩旗 | `y0 = 0.055LH` 正弦下垂，每 18px 一面三角旗，四色循环 `珊瑚/太阳黄/薄荷/天蓝` |
| 地面 | 9 行透视棋盘砖（行高 `((i+1)/9)^0.9` 递增），纵向砖缝向中心 5% 汇聚 |
| 木栈道 | 底部 `0.055LH`，`#8a5a3b / #b5794f / #6f452c` |
| 地平线边缘 | forest/peak 草叶、lake 白色浪花、volcano 灰烬短刺、cavern 晶色短刺 |

## 6. 已知缺口与风险

| # | 缺口 | 影响 | 优先级 |
|---|---|---|---|
| 1 | 精灵只有整体浮动，无姿态帧 | 喂食/玩耍/进化缺少表演感 | 高 |
| 2 | 进化形态仅换色 | 成长感弱 | 高 |
| 3 | HUD / 快捷栏图标仍是 emoji | 跨平台渲染不一致，可能显示方框 | 中 |
| 4 | 互动道具（食物/球/肥皂）没有视觉 | 只有粒子与气泡，缺少动作画面 | 中 |
| 5 | `drawScene` 的 `timeOfDay` 参数未使用 | 无昼夜/天气变化 | 中 |
| 6 | 场景装饰全部代码生成 | 换风格必须改 `renderer.js` | 低 |
| 7 | 精灵造型硬编码在 `sprites.js` | 新增精灵需同时改 config + sprites | 低 |
