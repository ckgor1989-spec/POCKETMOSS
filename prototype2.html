A · 极简沉浸底栏

场景画面全屏，底部只有 3 个标签切换（互动/散步/图鉴）。HUD 极简，只保留场景名、时间、电量。点击宠物弹出浮动菜单。

✓ 画面沉浸，群像最清晰
✗ 深层操作多一次点击
✓ 触摸区域最大化
✗ 状态数值需要下拉才能看

B · 侧边 HUD 栏

✗ 画面被占 20% 宽度
✓ 多宠一目了然

C · 全屏双叠 Grid

顶部叠加 HUD（场景名 + 所有宠物的状态条），底部叠加快捷动作栏（5 个按钮，含 AI 对话入口）。画面最丰富，但部分场景会被遮挡。

✓ 信息密度最高
✗ 画面被叠层遮挡
✓ 所有操作一触可达
✗ 群像场景的视觉呼吸感弱
